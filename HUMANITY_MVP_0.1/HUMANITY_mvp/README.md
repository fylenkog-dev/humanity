# HUMANITY MVP 0.1

Static, responsive landing-page prototype in Ukrainian.

## Run locally
Open `index.html` in a browser.

## Current scope
- Responsive landing page
- Story showcase cards (illustrative sample content)
- Values section
- Email link for story submissions (no backend or persistence)

## Not included yet
Authentication, database, publishing workflow, moderation, search, live map/geolocation, analytics, production deployment.
